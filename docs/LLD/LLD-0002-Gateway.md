# LLD-0002: Gateway Low-Level Design

## Summary

Gateway is a long-running data-plane service that receives remote MCP traffic
and forwards it to registered MCP server workloads.

The first implementation should be a minimal HTTP reverse proxy with route
configuration, health checks, structured logs, and metrics. MCP-aware parsing
can be added only after a policy and protocol-inspection design is approved.

## Runtime Modules

```text
gateway/
  cmd/gateway
  internal/config
  internal/routes
  internal/proxy
  internal/health
  internal/metrics
  internal/logging
  internal/policy   future
  internal/audit    future
```

## Request Flow

```text
HTTP request
  -> request id
  -> route lookup
  -> future authn/authz/policy check
  -> reverse proxy to upstream MCP server
  -> response
  -> metrics/logs/audit
```

## Route Model

Proposed route fields:

- route id,
- server name,
- version,
- upstream URL,
- timeout,
- retry policy,
- policy reference,
- enabled flag.

## Configuration Sources

MVP options:

- static file generated by Operator,
- watchable ConfigMap,
- Registry API polling or watch.

Recommended first implementation:

```text
Operator renders Gateway route ConfigMap
  -> Gateway watches or reloads config
```

## Health Endpoints

Proposed endpoints:

- `/healthz`: process alive,
- `/readyz`: route config loaded,
- `/metrics`: Prometheus metrics.

## Metrics

- `kavrynt_gateway_requests_total`
- `kavrynt_gateway_request_duration_seconds`
- `kavrynt_gateway_upstream_errors_total`
- `kavrynt_gateway_routes`
- `kavrynt_gateway_rejected_requests_total` after policy exists.

## Security Controls

Initial:

- non-root container,
- read-only root filesystem,
- no service account token unless needed,
- TLS configuration planned but not assumed.

Future:

- client identity,
- server identity,
- MCP tool-level authorization,
- audit event signing or durable audit sink.

## Tests

- route lookup unit tests,
- reverse proxy success/failure tests,
- timeout tests,
- invalid config tests,
- metrics tests,
- container smoke test,
- Helm render/lint.

## Open Questions

- Transparent proxy or MCP-aware proxy for MVP?
- How are route updates delivered?
- What identity token does the Gateway trust?
- What is the first audit event sink?
